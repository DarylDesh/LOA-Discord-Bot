# LOA Discord Forum Bot — Complete Package

Use `SETUP_GUIDE.md` for the full beginner instructions.

## Included
- `bot.py` — finished bot
- `.env.example` — configuration template
- `START_BOT.bat` — Windows one-click launcher
- `TEST_BOT.bat` — basic syntax check
- `requirements.txt` — required Python packages
- `.gitignore` — protects `.env` from normal Git commits
- `SETUP_GUIDE.md` — full setup guide

## Features
- Watches one Leave of Absence Forum
- Automatically applies `Pending`
- Pings one configurable reviewer role
- Persistent status buttons
- Restricts buttons to the reviewer role
- Preserves unrelated forum tags
- Posts an audit message showing who changed the status

Never share your `.env` file or Discord bot token.
